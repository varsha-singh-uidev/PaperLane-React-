# Paperlane – A Minimal Note-Taking Web App

Paperlane is a responsive note-taking web application built with React that allows users to create, organize, and manage notes with a clean and distraction-free interface.
The app focuses on simplicity while still providing essential features like note creation, search, filtering, and customization through themes and user preferences.

## 🚀 Features
* Create and manage notes with custom covers
* Optional password protection for notes
* Search notes by title
* Sort notes by title, created date, or last updated
* Filter notes (locked / unlocked)
* Light and Dark theme support
* Adjustable font size preferences
* LocalStorage-based persistence (no backend required)
* Reset app functionality

## 🧠 Tech Stack
* React (Functional Components + Hooks)
* React Router
* Tailwind CSS
* LocalStorage (for state persistence)

## 🎯 Purpose
This project was built to strengthen frontend fundamentals, including state management, component architecture, and UI/UX design, while implementing real-world features like theming, filtering, and data persistence.
